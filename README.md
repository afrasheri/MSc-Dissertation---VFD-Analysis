# MSc Dissertation - VFD Analysis

This repository contains the Python source code developed as part of an MSc dissertation focusing on the operational and energy performance of Variable Frequency Drives (VFD)-controlled pumps and engine-room fans in maritime systems.

# Repository Contents

The repository contains the two main stages of the dissertation analysis pipeline:

### MSc_Dissertation_VFD_Savings_Report.py 

Processes the available vessel operational data and generates vessel-level VFD savings reports in Excel format.

# MSc_Dissertation_Dasboard.py 

Processes the generated vessel reports and creates an interactive offline HTML dashboard for the dissertation analysis.

The dashboard includes analysis of:
- VFD utilization and operating modes
- Energy performance and savings
- Operational drivers and correlations
- Equipment-level and vessel-level performance indicators

# Data

The operational datasets used for this research were provided by the collaborating shipping company and contain proprietary information. For confidentiality reasons, the original datasets and generated vessel-level data files are not included in this public repository. The repository therefore contains only the Python source code developed for the dissertation.
